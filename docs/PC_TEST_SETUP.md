# Installazione sul PC di test

Questa guida descrive l'installazione e il collegamento read-only di AI Trading Indicator a MetaTrader 5.

> **PAPER ONLY**
>
> La release corrente non contiene funzioni per l'invio di ordini.  
> MetaTrader 5 viene utilizzato esclusivamente come sorgente dati.

## Prerequisiti

Installare sul PC Windows:

- Git;
- Python 3.11 a 64 bit;
- Node.js;
- MetaTrader 5;
- Visual Studio Code, facoltativo.

Verificare le installazioni da PowerShell:

```powershell
git --version
python --version
node --version
npm --version
